A tournament management system I built for my role as Tournament Director at Ravens Table Tennis Club. It runs real events end to end: entries, group draws, knockout brackets, table-by-table scheduling, live results and medals.

Version 2.0 is a full rebuild in Next.js, replacing the static version 1.0 that is still published on GitHub Pages. It ran the Cape Town Open 2026 — the live site below is that tournament's men's draw, in its own event theme.

- Next.js App Router with a signed-in control panel (JWT sessions via jose, bcrypt password hashing) and a separate public site for players and spectators
- MongoDB with Mongoose models for tournaments, events, entries, groups, knockouts and schedules; hosted on MongoDB Atlas
- Per-tournament public site themes, so a major event can get its own design while sharing the same pages
- Server-side PDF generation for scorecards, brackets and schedules with Puppeteer, and Excel entry import/export with ExcelJS
- Version 1.0: a multi-tournament static site generator with an Express control panel, auto-deployed to GitHub Pages by GitHub Actions
